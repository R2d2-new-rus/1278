# Парсер "Мой Арбитр"

Парсер для автоматического поиска арбитражных дел на сайте https://www.arbitr.ru/ с фильтрацией по заданным параметрам и формированием отчета.

## Функционал

- Поиск дел в арбитражных судах по России
- Фильтрация по:
  - Суду (отделение)
  - Периоду дат
  - Сумме дела (минимум и максимум)
  - Наименованию ответчика
- Формирование отчетов в формате:
  - JSON
  - CSV
  - HTML
- Сводка по найденным делам

## Использование

### Базовая команда

```bash
python main.py --court chel --from 2026-07-01 --to 2026-07-31 \
               --min 3000000 --max 25000000 --defendant АО
```

### Параметры

| Параметр | Описание | Пример |
|----------|---------|--------|
| `--court` | Сокращение суда | `chel`, `msk`, `spb`, `ekb`, `nov` |
| `--from` | Начальная дата | `2026-07-01` |
| `--to` | Конечная дата | `2026-07-31` |
| `--min` | Минимальная сумма дела | `3000000` |
| `--max` | Максимальная сумма дела | `25000000` |
| `--defendant` | Наименование ответчика | `АО`, `ООО`, `Компания` |
| `--output` | Файл для сохранения результатов | `report.json` |
| `--format` | Формат отчета | `json`, `csv`, `html` |

### Примеры использования

#### Поиск дел в Челябинском суде (JSON)
```bash
python main.py --court chel --from 2026-07-01 --to 2026-07-31 \
               --min 3000000 --max 25000000 --defendant АО \
               --output chelabinsk_report.json --format json
```

#### Поиск дел в Московском суде (CSV)
```bash
python main.py --court msk --from 2026-01-01 --to 2026-06-30 \
               --min 1000000 --max 10000000 --defendant ООО \
               --output moscow_report.csv --format csv
```

#### Поиск дел в Санкт-Петербургском суде (HTML)
```bash
python main.py --court spb --from 2026-06-01 --to 2026-08-31 \
               --min 500000 --max 5000000 --defendant Компания \
               --output spb_report.html --format html
```

## Выходные данные

### JSON формат
```json
{
  "timestamp": "2026-07-09T15:30:00",
  "search_parameters": {
    "court": "chel",
    "date_from": "2026-07-01",
    "date_to": "2026-07-31",
    "sum_min": 3000000,
    "sum_max": 25000000,
    "defendant": "АО"
  },
  "summary": {
    "total_cases": 5,
    "total_sum": 50000000,
    "average_sum": 10000000
  },
  "cases": [...]
}
```

### CSV формат
Таблица с колонками:
- Номер дела
- Дата регистрации
- Описание
- Ответчик
- Сумма
- Статус

### HTML формат
Красиво оформленный HTML отчет с таблицей, графиками и сводкой.

## Расширение

### Добавление новых судов

Отредактируйте словарь `COURT_CODES` в файле `parser/arbitr_parser.py`:

```python
COURT_CODES = {
    'chel': '74',  # Челябинский арбитражный суд
    'msk': '7',    # Московский арбитражный суд
    # Добавьте новый суд:
    'your_court': 'code',
}
```

### Модификация формата отчета

Отредактируйте методы в файле `utils/report_generator.py`:
- `_generate_html()` для изменения HTML шаблона
- `_generate_summary_dict()` для добавления новых полей сводки

## Требования к сайту
